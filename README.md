# Python File Counter

## 📌 Description
A Python mini-project that counts files, folders, and file types in a selected directory and generates a report.

## ✨ Features
- Count total files
- Count total folders
- Display file names
- Count file extensions
- Generate `report.txt`
- Handle invalid folder paths

## 🛠 Technologies Used
- Python 3.11
- os module

## ▶️ How to Run

```bash
python main.py
```
